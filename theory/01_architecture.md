# Архитектура RecursiveMAS

## Проблема

Обычные мульти-агентные системы передают информацию через **текст**:
```
Агент A → [декодирует в текст] → Агент B → [энкодирует обратно] → ...
```

Проблемы:
1. **Дорого** — каждый агент генерирует текст (m × |V| × d_h операций на шаг)
2. **Медленно** — авто-регрессивная генерация текста занимает время
3. **Плохо обучается** — градиенты затухают при прохождении через text decode → encode

## Решение: Латентная коммуникация

```
Агент A → [latent vector h] → RecursiveLink → [latent vector h'] → Агент B
```

Текст декодируется **только один раз** — последним агентом в последнем round'е.

## Компоненты

### 1. RecursiveLink (Inner)
Внутри каждого агента. Позволяет агенту генерировать «латентные мысли» — скрытые представления без текстового декодирования.

```
R_in(h) = h + W2 · GELU(W1 · h)
```

- `h` — last-layer hidden state агента
- Результат используется как input embedding для следующего шага того же агента
- Residual connection сохраняет семантику, MLP учит только distributional shift

### 2. RecursiveLink (Outer)
Между агентами. Позволяет передавать латентные представления между моделями разной архитектуры и размера.

```
R_out(h) = W3 · h + W2 · GELU(W1 · h)
```

- `W3` — линейный слой для маппинга между разными hidden dimensions
- Остальное аналогично Inner Link

### 3. Latent Thoughts Generation
Каждый агент авто-регрессивно генерирует m шагов латентных мыслей:
```
e_{t+1} = R_in(h_t)    # last-layer → input embedding
h_{t+1} = f_θ([E; e_{t+1}])  # forward pass
```

Результат: последовательность латентных мыслей H = [h_t, h_{t+1}, ..., h_{t+m}]

### 4. Recursive Loop
Все агенты соединены в цикл:
```
A1 → A2 → ... → AN → A1 → A2 → ... (n rounds)
```

- Каждый round: агенты по очереди генерируют латентные мысли, передают их дальше
- Только в последнем round'е агент AN декодирует текст

## Почему это эффективно?

### Runtime complexity
- **Text-based:** Θ(N · (m|V|d_h + (t+m)d_h² + (t+m)²d_h))
- **RecursiveMAS:** Θ(N · (md_h² + (t+m)d_h² + (t+m)²d_h))

Разница: `m|V|d_h` vs `md_h²`. Так как `d_h << |V|` (напр. 4096 << 151936 для Qwen3), выигрыш существенный.

### Gradient stability
- **Text-based:** градиенты затухают через decode→encode (norm ≈ ε << 1)
- **RecursiveMAS:** residual connection сохраняет градиенты (norm ≈ 1)

Это значит: чем глубже рекурсия, тем больше преимущество RecursiveMAS.
